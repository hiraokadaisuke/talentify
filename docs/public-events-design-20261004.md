# 一般向け来店情報ページの更新（2026-10-04）

## 対象
- `/` と `/events` の表示を `components/events/EventsBoard.tsx` に共通化。
- コンパクトなステージ背景、日付別件数、地域・店舗名・演者名検索。
- 実際の公開情報の演者写真を使用。店舗名を先に、来店日・演者名・地域・公開された時間を表示。
- 今週は今日から7日間。日付別にまとめる。
- 空の検索結果では案内と、条件に合う今後の予定（存在する場合）を表示。
- キャンセル・終了済み・過去の予定は一覧から除外。公開条件は既存の取得処理を維持。
- 写真未登録・読み込み失敗は人物アイコンに切り替える。ダミー写真やダミー案件は本番表示に追加しない。
- 地域・店舗の導線を主にし、演者検索とサービス紹介への導線も維持。
- 一般ページのヘッダー背景の不正な透明度指定を修正。

## 確認
ローカルのHTTPフィクスチャで既存Supabaseレスポンス形式を再現し、DBへの書き込みなしで検証。
- 1440 / 1024 / 390 / 320px：横はみ出しなし。
- 長い店舗名・演者名、写真あり／なし／失敗、検索結果なし。
- 地域検索、名前検索、今週の日付別表示、トップ表示。
- ブラウザーのページエラーなし。

実データによる一覧は公開済み件数に依存する。個別詳細・店舗一覧・演者一覧の全面改修は今回の対象外。
