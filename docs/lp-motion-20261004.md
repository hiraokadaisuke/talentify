# LPのモーション（2026-10-04）

対象 `/service`。文章と素材は変更せず、ServiceMotion のクライアント側拡張と専用CSSを追加。

- FVの文字・人物・UIを順に表示。PCのポインター移動とスクロールでレイヤーごとに異なる距離を移動。
- セクション、機能カード、手順をスクロールで順に表示。
- PCの機能カードはポインター位置で傾きと照明が変化。
- 6ステップの光が順に動き、接続図の線も流れる。
- 管理画面の角度をスクロールで調整。人物写真・CTAにホバー反応。最終CTAに光の移動。
- ページ上端の読了位置表示、現在位置に応じたナビゲーション色。
- 「動きを止める」ボタン、prefers-reduced-motion、画面外と非表示タブの装飾停止。
- コンテンツはサーバー出力のまま。JSなしでも表示。スクロールを乗っ取らず、独自のスクロール操作・重いライブラリ・追加画像は導入しない。

本番ビルド成功。ローカルのモバイル相当計測（390px、遅延150ms、200KB/s、CPU4倍制限）ではLCP 1240ms、CLS 0、初期リソース転送約516KB。実ユーザー環境の計測値ではない。
