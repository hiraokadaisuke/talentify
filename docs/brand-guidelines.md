# 来店ナビ Brand Guidelines v1.0

> **Status: APPROVED / Source of Truth**
>
> 本ドキュメントは、来店ナビのロゴ、LP、一般公開ページ、業務UI、イベントページ、AIポスター、SNS素材、今後追加する機能のデザイン・コピー判断における基準です。
> 迷った場合は「派手にするか」ではなく、**どの利用面か**を先に判定し、本ガイドに従ってください。

## 1. Brand Identity

### 正式名称

- 日本語正式名称: **来店ナビ**
- 英字表記: **RAITEN NAVI**
- ユーザー向け表記では原則として「来店ナビ」を使用する
- Talentify / talentify は移行期間中の内部技術名としてのみ許容する
- 外向けに「来店Navi」「RAITEN-NAVI」など別表記を増やさない

### サービス定義

来店ナビは、**パチンコ店と演者をつなぎ、来店イベントを「探す・依頼する・管理する・告知する・広げる」ための来店イベントプラットフォーム**。

業務側では、演者検索、スケジュール、オファー、メッセージ、見積・契約・請求、レビューまでを一連で扱う。

集客側では、AIポスター作成、SNS配信支援、イベントPR・露出強化などを通じ、店舗の来店イベントを一般ユーザーへ届けやすくする。

### ブランドが提供する感情

- 見つけたくなる
- 参加したくなる
- 告知したくなる
- イベントが動き出す期待感
- 店舗・演者双方にとって「進めやすい」安心感

### ブランドキーワード

**目立つ / つながる / 広がる / 盛り上がる / ワクワク / 発見 / 注目 / スピード / イベント / ナビゲーション**

## 2. Brand Personality

来店ナビは次の5つを同時に満たす。

1. **Energetic** — イベントらしい勢いと躍動感
2. **Modern** — 古いパチンコ広告ではなく、現在のデジタルサービスらしさ
3. **Visible** — 情報が埋もれず、重要なものが一目で分かる
4. **Friendly** — 店舗・演者・一般ユーザーが入りやすい
5. **Trustworthy** — 契約・請求・案件管理にも使える信頼感

### 目指さないもの

- 昔ながらの情報過多なパチンコチラシ
- 原色を無秩序に並べただけの派手さ
- 水商売・ナイトビジネスに寄りすぎた世界観
- ギャンブルの勝敗や出玉を煽る表現
- 地味で無機質な一般SaaS
- 装飾優先で操作性が落ちたUI

## 3. Core Design Principle

### ブランド全体の原則

**「外はワクワク、中は分かりやすく。」**

来店ナビは全画面を同じテンションにしない。

### A. LP / 一般公開 / イベントPR

最もブランドの高揚感を出してよい領域。

- ダークネイビーを土台にする
- オレンジ・レッドオレンジ・イエローの発光や光線を使用可能
- スポットライト、光の筋、星、矢印、モーション感を使用
- 大きな見出しと強いコントラスト
- 人、会場、来店イベントの期待感を主役にする

### B. 業務UI / ダッシュボード / 見積・請求 / 設定

**読みやすさと操作性を最優先する。**

- メインコンテンツ背景は **白または極薄グレー**
- ダークネイビーはサイドバー・ヘッダー・限定的な面に使用
- オレンジ・イエローはCTA、注目、新着など限定的に使用
- 発光・レンズフレア・派手なグラデーションを入力フォームや表には使用しない
- 1画面内のブランドアクセント面積を抑える
- ユーザーが「何をすればいいか」を装飾より先に理解できること

### C. AIポスター / SNSクリエイティブ

最も表現幅を広く取れる領域。

- ブランド色を強く使用可能
- 写真、光、ダイナミックな文字、イベント感を使用可能
- ただし情報階層は明確にし、日付・店舗・演者名など重要情報を潰さない

### Color Usage Rule

- **一般公開:** Navy 60 / White 20 / Warm Accent 20 を目安
- **業務UI:** White・Gray 80〜90 / Navy 5〜15 / Warm Accent 5〜10 を目安

- エラー色とブランドオレンジを混同させない

## 5. Typography

### 基本方針

- 日本語見出し: **Noto Sans JP 800–900 相当**
- 日本語本文: **Noto Sans JP 400–600 相当**
- 英数字/UI: **Inter 400–700 相当**
- 代替: システムゴシックを使用し、可読性を優先

### 表現

- 見出しは太く、短く、力強く
- 本文は装飾せず読みやすく
- 斜体、筆記体、手書き文字はLP・ポスターの装飾に限定
- 業務UIでは手書き風フォントを使用しない

### ロゴ

ロゴの「来店ナビ」は**独立したブランドワードマーク**であり、通常テキスト用フォントで再現しない。

## 6. Logo Policy

### Primary Logo

承認済みの横型ロゴを正式なプライマリーロゴとする。

構成:
- 左: 位置・ナビゲーションを想起するシンボル
- 右: 「来店ナビ」
- 補助表記: RAITEN NAVI

シンボルは **位置 / 発見 / 上向きの動き / 注目 / 光** を表す。

### Favicon / App Icon

- 正式なシンボル単体版を使用
- 文字を入れない
- ダークネイビーの角丸背景
- オレンジ〜イエローのマークと白い光を使用
- 小サイズでは細かな装飾を追加しない

### Clear Space

ロゴ外周には、シンボル内の白い星の横幅を **1x** とした場合、最低 **1x** の余白を確保する。

### Minimum Size

- 横型ロゴ: Webで原則 180px 幅以上
- シンボル単体: 24px 以上
- 16px / 32px のブラウザタブでは専用faviconを使用

### 禁止事項

- ロゴの縦横比を変える
- 独自に色を変更する
- シンボルと文字の位置関係を変更する
- ロゴの一部を切り取る
- 過剰な影・縁取り・発光を後付けする
- 背景とのコントラストが不足した状態で使用する
- faviconに横型ロゴを縮小して使用する

## 7. Photography & Key Visual

### 推奨

- 来店イベントの期待感が伝わる人物
- 笑顔、動き、視線、会場の光
- スポットライト、群衆、イベント会場
- スマホでイベントを探す・共有する瞬間
- パチンコホールを示す場合も、機械より「人・イベント」を主役にする

### 避ける

- 出玉・大当たり・金銭的成功を主役にしたビジュアル
- 過度な札束・コイン・勝敗表現
- 性的・ナイトビジネス的な演出への寄せすぎ
- 情報が読めなくなる過剰な光加工
- 実在人物を無断で連想させるAIビジュアル

## 8. Icon & Motif

推奨モチーフ:
- Location pin
- Arrow / Navigation
- Spotlight
- Star / Spark
- Calendar
- Megaphone
- Share
- Growth
- People / Connection

### Rule

- 星・光・稲妻の装飾はPR面で使用し、設定画面などでは濫用しない

## 9. UI Rules

### 業務UIの基準

1. 白背景を基本とする
2. 1カード = 1目的
3. 重要CTAは1画面に1つを基本とする
4. CTAはOrange、通常操作はNavy/Neutral
5. 文字コントラストを装飾より優先
6. 状態は色だけでなくテキスト/アイコンでも示す
7. モバイルでは装飾を減らし、操作領域を優先
8. 発光表現をフォーム・表・契約・請求画面に持ち込まない

### 公開イベントカード

優先順位:
1. 演者 / イベント名
2. 日付
3. 店舗
4. 開催時間
5. CTA
6. PRラベル・注目情報

## 10. Copy & Voice

### 基本トーン

**短い / 前向き / 分かりやすい / 行動が分かる / ワクワクする**

### 推奨語

- 目立たせる
- 盛り上げる
- 広げる
- 見つかる
- 届ける
- ワクワク
- 注目
- 来店イベント
- スムーズ
- かんたん
- つながる

### 使用しない言葉・方向

**「熱く」** はブランドコピーとして使用しない。

また以下は原則避ける:
- 激アツ
- 爆発
- 勝てる / 勝率
- 絶対 / 確実
- 出る / 出すことを示唆する表現
- 根拠のない「No.1」「集客最大化」「必ず集客できる」

来店ナビの高揚感は、**イベント体験・発見・人とのつながり**に向ける。遊技結果を煽る表現には向けない。

### コピー例

良い:
- 「来店イベントを、もっと目立たせる。もっと盛り上げる。」
- 「話題の来店イベントを見つけよう。」
- 「イベント情報を、もっと多くのファンへ。」
- 「演者探しから告知まで、来店イベントをひとつに。」

避ける:
- 「来店イベントをもっと熱く。」
- 「激アツ来店を見逃すな。」
- 「この日は勝てる。」
- 「集客が必ず伸びる。」

## 12. Future Feature Direction

### AIポスター作成

- 店舗担当者が短時間で「見せられる告知物」を作れる
- テンプレートはブランド統一より、イベント用途ごとの選択肢を持たせる
- 日付・店舗・演者名など重要情報を自動で読みやすく配置

### SNS自動配信

- 「自動化」そのものより「手間なく届けられる」を価値として見せる
- SNSブランドの色をUI全体へ持ち込まない
- 投稿プレビューを重視する

### イベントPR上位表示

- 一般ユーザー画面で明確に「PR」「注目」等と表示
- 通常掲載との違いを視覚的に示す
- 派手さだけでなく、イベント情報の分かりやすさを維持する

## 13. Decision Checklist

新しい画面・画像・コピーを作る際は以下を確認する。

- これは「PR面」か「業務面」か
- 見た瞬間に目的が分かるか
- 派手さが情報理解を邪魔していないか
- 来店ナビらしいNavy + Warm Accentがあるか
- 業務UIなら白背景を維持しているか
- 「熱く」など過度な煽り文言を使用していないか
- 遊技結果を示唆する表現になっていないか
- モバイルでも読みやすいか
- ロゴ・色・フォントを勝手に改変していないか

## Approved Direction Summary

**来店ナビ = 「イベントの高揚感」と「業務ツールの分かりやすさ」を両立するブランド。**

- 外向き: ダークネイビー × オレンジ / レッド / イエロー、光・動き・イベント感
- 内向き: 白背景、整理された情報、必要な場所だけブランドアクセント
- コピー: 勢いはあるが煽りすぎない
- 主役: パチンコの勝敗ではなく **来店イベント、人、発見、つながり、告知**
